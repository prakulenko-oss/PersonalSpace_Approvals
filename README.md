# Персональний Кабінет — прототип

Клікабельний прототип HR-порталу самообслуговування співробітника та керівника
у стилі Microsoft 365 / Fluent UI. Призначення — демонстрація сценаріїв бізнесу
та передача референсу розробникам. **Усі дані, ПІБ та документи — вигадані.**

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b && vite build — перевіряє типи та збирає dist/
```

Стек: React 19, TypeScript, Vite, React Router, Fluent UI v9, lucide-react.

## Сторінки

| Маршрут | Сторінка | Що демонструє |
|---|---|---|
| `/` | Головна (Dashboard) | Лаунчер «Мої сервіси», віджети, умовна картка прощального опитування |
| `/approvals` | Центр затверджень | Нотифікації та погодження документів з інтегрованих систем |
| `/manager-space` | Простір Менеджера | Команда, кадрові операції, Довіреності / КЕП для керівника (`?section=poa`) |
| `/poa` | Довіреності / КЕП | Версія для співробітника: довіреності функції, замовлення на керівника |
| `/bank-memo` | Зарплатний банк | Вибір банку для зарплатного проєкту, покроковий флоу з листом |
| `/credit` | Кредит від компанії | Безвідсотковий кредит: калькулятор, лист у HR, погашення з QR, ваги з котиком |
| `/safety` | Охорона праці | Інструктажі та підтвердження |
| `/exit-interview` | Exit-інтерв'ю | Прощальне опитування: 6 кроків, 5 обов'язкових питань, комплаєнс |

## Структура

- `src/pages/*` — сторінки (одна сторінка — один файл; складні модулі — папка)
- `src/pages/credit/` — модуль кредиту: `loanData.ts` (налаштування, демо-дані), `ui.tsx` (спільні атоми, токени, глобальні анімації), `scales.tsx`, `apply.tsx`, `letter.tsx`, `repay.tsx`, `reviewHistory.tsx`
- `src/pages/exitInterviewData.ts` — довідники exit-інтерв'ю (1:1 з Excel HR)
- `src/pages/managerUi.tsx` — спільні примітиви Простору Менеджера (модалки, шторки, тости)
- `src/components/TopBar.tsx` — верхня панель
- `src/data/*` — демо-дані головної та затверджень
- `src/assets/` — вбудовані іконки (base64) та зображення, що імпортуються через Vite

## Домовленості

- Збірку перевіряти командою `npm run build` (не `tsc --noEmit`): невикористані імпорти ламають збірку.
- Демо-перемикачі станів (кредит, exit-інтерв'ю, головна) — лише для показу; у проді стани приходять із систем-джерел.
- Параметри програм (ліміти кредиту, строки, реквізити, тексти) винесені константами вгорі відповідних файлів даних.
